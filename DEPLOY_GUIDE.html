🚀 AI Job Search OS - Deploy Guide

Быстрый деплой на Vercel за 5 минут

1Создать GitHub репозиторий

Откройте ссылку ниже в браузере:

📦 Открыть GitHub New Repository

Имя репозитория: ai-job-search-os

Public или Private - на ваш выбор

Нажмите "Create repository"

2Запушить код на GitHub

Выполните в терминале (скопируйте и вставьте):

cd "/Users/djo/projekt_ALL/job searcher AI"

git remote add origin https://github.com/YOUR_USERNAME/ai-job-search-os.git

git push -u origin main
⚠️ Замените YOUR_USERNAME на ваш GitHub username!

3Задеплоить на Vercel

Откройте ссылку ниже:

🔷 Открыть Vercel Deploy

Действия:

  1. Нажмите "Import Git Repository"
  2. Выберите ваш репозиторий ai-job-search-os
  3. Root Directory: apps/web
  4. Build Command: cd ../.. && pnpm install && pnpm build
  5. Environment Variables:
    • NEXT_PUBLIC_API_URL = http://localhost:3001 (для тестов)
  6. Нажмите "Deploy"

✅ Готово!

Через 2-3 минуты ваш frontend будет доступен по URL:

https://ai-job-search-os.vercel.app

⚠️ Важно про API

Frontend на Vercel должен иметь доступ к API:

  • Для тестов: Оставьте API локально запущенным
  • Для production: Задеплойте API на Render

Полная инструкция: DEPLOY_INSTRUCTION.md
